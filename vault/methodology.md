# Методологія квізів для Матвія

## Стандарт квізу (з L1 / 31.05.2026)

- **30 завдань** — 3 блоки × 10 задач (раніше було 3×6=18, оновлено для drill-to-automaticity).
- **3 числові варіації на завдання** — randomly обирається з масиву `v`, плюс перемішування позицій відповідей. Переграти можна — числа будуть нові.
- **Hybrid format:** неправильна відповідь → підказка (метод вирішення) → друга спроба. Бал зараховується **тільки якщо правильно з 1-ї спроби** (firstTryCorrect). На другу спробу — тільки навчальний фідбек.
- **12-бальна шкала** за відсотком first-try correct (див. CLAUDE.md проєкту або існуючі квізи для маппінгу).
- **Multilang:** UK / EN / ES з locale-aware десятковим розділювачем (кома для uk/es, крапка для en).
- **Таймер** — реальний час від старту до результату.
- **System font stack** — `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, ...` (cross-platform Cyrillic, без Mac-«квадратиків»).
- **Single-file HTML** — без зовнішніх залежностей, працює офлайн.

## Слабкі місця Матвія (постійно цілимо)

1. **Не скорочує** результат до кінця (наприклад, 6/12 замість 1/2).
2. **Забуває виділяти цілу частину** з неправильного дробу (наприклад, 9/4 замість 2¼).
3. **Плутається з дробами від часу** (частка від години/хвилини, переведення у секунди).

При проєктуванні нового квізу — **завжди** питай себе: «де тут можна вшити повтор скорочення / виділення цілої?». Якщо тема прямо не дробова — закладай у дистрактори.

## Патерни дистракторів

**Філософія:** дистрактор повинен виглядати як **реальна помилка**, яку Матвій міг би зробити. Тоді при wrong-answer він пізнає свою типову помилку, а підказка стає intervention.

Типові помилки для арифметики дробів:
- **±:** додав чисельники + знаменники окремо без спільного денома (1/2 + 1/3 = 2/5 wrong).
- **±:** скоротив занадто рано/неправильно, або не скоротив зовсім.
- **±:** залишив неправильний дріб без виділення цілої.
- **×:** зробив додавання замість множення (типова на ранніх етапах).
- **×:** перевернув один з дробів без потреби (плутанина з ÷).
- **÷:** забув перевернути другий дріб → просто перемножив.
- **÷:** перевернув не той дріб (перший замість другого).
- **Mixed:** забув перевести мішаний у неправильний перед операцією.

Для **відсотків/переведень:**
- digit-concat (¾ → 0,34)
- забутий ×100 (0,75 → 0,75% замість 75%)
- забутий ÷100 (75% → 75 замість 0,75)
- нескорочений (40% → 40/100 замість 2/5)

## File-naming convention

Quiz HTML: `quizzes/<тема>-<клас>[-<програма>]-<дата>.html`
- `<тема>` — латиницею (drobi, vidsotky, proportsii, geometriya, ...)
- `<клас>` — `<N>klas` (7klas)
- `<програма>` — `ispanska` для Матвія (1º ESO іспанської школи)
- `<дата>` — `YYYY-MM-DD`

Lesson note: `vault/lessons/L<NN>-<YYYY-MM-DD>-<slug>.md`
- `<NN>` — 2-digit lesson number (L01, L02, ..., L27)
- `<slug>` — коротке slug теми

## Кольорове кодування фаз (для UI/дизайну квізу)

- **Phase 1 (шкільний фундамент):** indigo `#4f46e5` → `#6366f1`
- **Phase 2 (літо):** teal `#0d9488` → `#14b8a6`
- **Phase 3 (фінал):** amber `#d97706` → `#f59e0b`

Можна варіювати в межах фази — головне щоб у одній фазі квізи виглядали як «серія».

## Шаблон-стартер

`quizzes/drobi-arifmetyka-7klas-ispanska-2026-05-31.html` (L1) — добрий приклад:
- Data shape: `[aw, ap, aq, bw, bp, bq]` — мішаний дріб як whole + p/q.
- `GEN[dir].apply(null, variation)` для spreading.
- Generic `canon(num, den)` для приведення до form: int/frac/mixed.
- `pickDistr()` фільтрує невалідні (від'ємні знам., null) і дедуплікує.

Для іншого типу задач (не арифметика, а наприклад «обери правильний варіант») — `drobi-desyatkovi-vidsotky-7klas-ispanska-2026-05-27.html` має directional pattern (f2d, d2f, ...).

## Валідація перед deploy

Завжди перед commit:
1. `node --check` синтаксис JS (extract `<script>` block).
2. Math sanity: пройти всі варіації, перевірити correct == expected з formula, дистрактори ≠ correct.
3. 100-200 randomized buildRuntime прогонів — щоб піймати edge cases в pickDistr.
4. Open in browser, mentally run першу задачу.

Тоді commit + push, перевір Vercel deploy (curl URL до появи нового контенту).
