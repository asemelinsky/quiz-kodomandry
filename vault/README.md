# Quiz vault — Матвій, програма повторення 2026

Робоча тека для планування квізів. Тут живуть план, методологія та нотатки по кожному уроку.

## Структура

- **[plan.md](plan.md)** — 27-урочний план на нд+ср з 31.05.2026 до 30.08.2026, з статусом кожного уроку (✅/⏳) та коротким описом.
- **[methodology.md](methodology.md)** — стандарт квізу (30 завдань, hybrid format, multilang), слабкі місця Матвія, патерни дистракторів, file-naming convention.
- **[lessons/](lessons/)** — детальні нотатки по кожному уроку: фіксація точних задач (щоб не повторювати), дистрактори, спостереження після зустрічі.

## Як користуватись (для майбутньої Claude-сесії)

Перед створенням нового квізу:
1. Відкрий [plan.md](plan.md) → знайди поточний L# і тему.
2. Відкрий [methodology.md](methodology.md) → пригадай стандарт + слабкі місця.
3. Сканний [lessons/](lessons/) для всіх попередніх уроків, які перетинаються тематично (особливо коли готуєш **drill-fiesta** — щоб взяти НЕ ті самі числа, а нові).
4. Створи новий файл `lessons/L<NN>-<YYYY-MM-DD>-<slug>.md` ДО створення HTML — спочатку фіксація задач, потім код.
5. Після створення квізу: онови `plan.md` (статус ✅), додай Live URL у lesson note.
