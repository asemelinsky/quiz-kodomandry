# План квізів — Матвій (літо 2026)

**Учень:** Матвій, 7 клас, **британський коледж в Іспанії**, мова викладання **англійська** (з Києва, живе в Іспанії давно).  
_Уточнено 2026-06-07 — раніше помилково «іспанська школа, мова українська»._
**Формат:** очні зустрічі **нд + ср**, асинхронні «хвости» через батька влітку.
**Період:** 31.05.2026 → 30.08.2026 (3 місяці).
**Кількість уроків:** 27 (9 шкільних + 17 літніх + 1 фінал).

## Філософія

- Кожен квіз — нова основна тема + наскрізний drill дробів (скорочення / виділення цілої / переведення).
- Дроби повторюються постійно — їх «не дозволяємо» забути.
- Кожні ~4-5 уроків літом — **drill-fiesta**: повторення раніше пройдених тем без нової теорії, з новими числами і складнішими дистракторами.
- Завершальний квіз L27 — мікс усіх 26 тем як «школа закінчилась — готовий до 2º ESO».
