## D1 — Linear Algebra (audit 2026-06-07)

### Term 1: eigenvalue
- **Wikipedia:** https://en.wikipedia.org/wiki/Eigenvalues_and_eigenvectors (accessed 2026-06-07) — "For a square matrix A, an eigenvector is a nonzero vector v such that Av = λv; the scalar λ is the corresponding eigenvalue (real or complex)."
- **MathWorld:** https://mathworld.wolfram.com/Eigenvalue.html — WebFetch returned 403 (Cloudflare block). Standard MathWorld definition (per knowledge): "Eigenvalues are a special set of scalars associated with a linear system of equations…"
- **Axler/Strang:** Axler "LADR" Def 5.5: "A scalar λ ∈ F is called an eigenvalue of T ∈ L(V) if there exists v ∈ V, v ≠ 0, such that Tv = λv."
- **Consensus definition:** A scalar λ (in the underlying field F, typically ℝ or ℂ) such that Av = λv for some **non-zero** vector v.
- **Our current quiz definition:** "A scalar λ such that Av = λv for some non-zero vector v"
- **Verdict:** ✅ matches.

### Term 2: span
- **Wikipedia:** https://en.wikipedia.org/wiki/Linear_span (accessed 2026-06-07) — "span(S) = {λ₁v₁ + λ₂v₂ + ⋯ + λₙvₙ | n ∈ ℕ, vᵢ ∈ S, λᵢ ∈ K}"; equivalently "the smallest linear subspace of V containing S."
- **MathWorld:** https://mathworld.wolfram.com/Span.html — 403.
- **Axler/Strang:** Strang Ch.2: "The span of a set of vectors is all linear combinations of those vectors."
- **Consensus definition:** The set of all **finite** linear combinations of those vectors.
- **Our current quiz definition:** "The set of all linear combinations of those vectors"
- **Verdict:** ✅ matches.

### Term 3: basis
- **Wikipedia:** https://en.wikipedia.org/wiki/Basis_(linear_algebra) (accessed 2026-06-07) — "A basis B of a vector space V over a field F is a linearly independent subset of V that spans V."
- **Axler/Strang:** Axler Def 2.26: "A basis of V is a list of vectors in V that is linearly independent and spans V."
- **Consensus definition:** A linearly independent subset/list of vectors that spans V.
- **Our current quiz definition:** "A linearly independent set of vectors that spans V"
- **Verdict:** ✅ matches (finite-dim scope implicit).

### Term 4: orthogonal (vectors)
- **Wikipedia:** https://en.wikipedia.org/wiki/Orthogonality_(mathematics) (accessed 2026-06-07) — "Two vectors u and v in an inner product space are orthogonal when ⟨u, v⟩ = 0."
- **Axler/Strang:** Axler Def 6.10: "Two vectors u, v ∈ V are called orthogonal if ⟨u, v⟩ = 0."
- **Consensus definition:** u ⊥ v iff ⟨u, v⟩ = 0 in an inner product space.
- **Our current quiz definition:** "Their inner product (dot product) is zero"
- **Verdict:** ✅ matches with minor nuance — dot product is ℝⁿ case; ℂⁿ uses Hermitian inner product.
- **Action taken:** Added Hermitian distinction in `explain`.

### Term 5: rank (of matrix)
- **Wikipedia:** https://en.wikipedia.org/wiki/Rank_(linear_algebra) (accessed 2026-06-07) — Primary definition: "rank = dimension of the vector space generated by its columns." Column rank = row rank is presented as a "fundamental theorem", not as the definition.
- **Axler/Strang:** Strang Ch.3 (5th ed): defines column rank first; then proves col rank = row rank.
- **Consensus definition:** rank(A) := dim(col A). Then THEOREM: dim(col A) = dim(row A).
- **Our previous quiz definition:** "The dimension of its column space (= dimension of its row space)"
- **Verdict:** ⚠️ minor issue — definition conflated with theorem.
- **Action taken:** Option text → "The dimension of its column space"; theorem moved to `explain`.

### Term 6: non-singular
- **Wikipedia:** https://en.wikipedia.org/wiki/Invertible_matrix (accessed 2026-06-07) — "An invertible matrix (non-singular, non-degenerate or regular) is a **square** matrix that has an inverse."
- **Consensus definition:** Square matrix that is invertible.
- **Our current quiz definition:** "If A is invertible, then A is also called non-singular"
- **Verdict:** ✅ matches.

### Term 7: linearly independent (cloze sentence)
- **Wikipedia:** https://en.wikipedia.org/wiki/Linear_independence (accessed 2026-06-07) — "vectors v₁,…,vₙ are linearly independent if a₁v₁+…+aₙvₙ = 0 can only be satisfied by aᵢ = 0."
- **Axler/Strang:** Axler Def 2.17 same.
- **Consensus definition:** Trivial-solution formulation.
- **Our previous quiz sentence:** "The columns of a matrix form a basis if and only if they are linearly _____."
- **Verdict:** ⚠️ scope issue — biconditional "columns form a basis ⇔ linearly independent" holds **only for square A**.
- **Action taken:** Added "square" qualifier to sentence.

### Term 8: diagonalizable
- **Wikipedia:** https://en.wikipedia.org/wiki/Diagonalizable_matrix (accessed 2026-06-07) — "A square n×n matrix A is diagonalizable if there exists an invertible P such that P⁻¹AP is diagonal." Equivalent: A has n linearly independent eigenvectors. Field matters.
- **Axler/Strang:** Axler Ch.5 same.
- **Consensus definition:** Square matrix A is diagonalizable iff A = PDP⁻¹ with D diagonal.
- **Our current quiz definition:** "Square matrix can be diagonalized if it has n linearly independent eigenvectors"
- **Verdict:** ✅ matches.

### Term 9: kernel / null space (cloze)
- **Wikipedia:** https://en.wikipedia.org/wiki/Kernel_(linear_algebra) (accessed 2026-06-07) — "ker(L) = {v ∈ V | L(v) = 0}."
- **Consensus definition:** Set of vectors mapped to zero.
- **Our current quiz definition:** "The set of vectors x such that Ax = 0"
- **Verdict:** ✅ matches.

### Terms 10–13: Collocations
- "solve a system of equations" — Standard mathematical English (Strang, Axler, all textbooks). ✅
- "singular matrix" — Standard antonym of non-singular: det = 0. ✅
- "compute eigenvalues" — Standard in numerical linear algebra (Trefethen-Bau, Golub-Van Loan). ✅
- "eigenvector corresponds to eigenvalue" — Standard phrasing across Axler, Strang, Wikipedia. ✅

### Term 14: orthonormal
- **Wikipedia:** https://en.wikipedia.org/wiki/Orthonormality (accessed 2026-06-07) — "A set {uᵢ} is orthonormal iff ⟨uᵢ, uⱼ⟩ = δᵢⱼ." Two conditions: unit norm + mutual orthogonality.
- **Axler/Strang:** Axler Def 6.22 same.
- **Consensus definition:** Unit-length vectors that are pairwise orthogonal.
- **Our current quiz definition:** "Unit-length vectors that are mutually orthogonal"
- **Verdict:** ✅ matches.

### Term 15: eigendecomposition
- **Wikipedia:** https://en.wikipedia.org/wiki/Eigendecomposition_of_a_matrix (accessed 2026-06-07) — "A = QΛQ⁻¹ where columns of Q are eigenvectors and Λ is diagonal of eigenvalues. **Only diagonalizable matrices can be factorized this way.**"
- **Consensus definition:** A factorization A = PDP⁻¹ that **exists iff A is diagonalizable**.
- **Our previous quiz definition:** "Factoring A as PDP⁻¹ using eigenvalues and eigenvectors"
- **Verdict:** ⚠️ moderate issue — does not state diagonalizability prerequisite.
- **Action taken:** Updated option text to include "diagonalizable"; added counter-example (shear matrix) to `explain`.

### Term 16: trace (of matrix)
- **Wikipedia:** https://en.wikipedia.org/wiki/Trace_(linear_algebra) (accessed 2026-06-07) — "tr(A) = Σᵢ aᵢᵢ for square A."
- **Verdict:** ✅ matches.

### Term 17: linear independence (free-text)
- **Wikipedia:** Same as Term 7.
- **Axler/Strang:** Axler Def 2.17.
- **Consensus model answer:** Both equivalent characterizations (trivial solution + no vector as combination).
- **Our model answer:** Both included.
- **Verdict:** ✅ matches.

### Term 18: SVD (singular value decomposition) — **STUDENT-FLAGGED**
- **Wikipedia:** https://en.wikipedia.org/wiki/Singular_value_decomposition (accessed 2026-06-07) — "The singular value decomposition of an m × n **complex** matrix M is a factorization of the form **M = UΣV\***" where:
  - U is m × m **complex unitary** (real orthogonal if M is real)
  - Σ is m × n **rectangular** diagonal matrix with non-negative real entries
  - V is n × n **complex unitary** (real orthogonal if M is real)
  - V\* denotes the **conjugate transpose**
- **Wikipedia:** https://en.wikipedia.org/wiki/Singular_value — strictly non-negative reals, conventionally in decreasing order.
- **Wikipedia:** https://en.wikipedia.org/wiki/Orthogonal_matrix — only real-valued; complex analog is unitary.
- **Axler/Strang:** Strang "Introduction to LA" 5th ed Ch.7: A = UΣVᵀ for real m×n A; Axler "LADR" Ch.7 uses unitary for complex.
- **Consensus definition:** For any m×n complex matrix M: M = UΣV\* with U (m×m) unitary, V (n×n) unitary, Σ (m×n) rectangular diagonal with non-negative real singular values.
- **Our previous model answer:** "SVD factorizes any matrix A as A = UΣVᵀ, where U and V are orthogonal matrices and Σ is a diagonal matrix of non-negative singular values."
- **Verdict:** ❌ **WRONG IN GENERAL CASE** — three issues:
  1. **U, V "orthogonal"** is correct only over ℝ. In general (complex) case they must be **unitary**.
  2. **Σ "diagonal"** is misleading — Σ is **rectangular m×n**, not square.
  3. **Transpose vs conjugate-transpose** — Vᵀ is correct only for real; in general V\*.
- **Action taken:** Rewritten model answer to include all three corrections; keyPhrases updated; threshold raised to 1.0 (all 4 required) to force learner to include "rectangular".

### Term 19: derive (a formula)
- **Wiktionary:** https://en.wiktionary.org/wiki/derive (accessed 2026-06-07) — "(logic) To deduce (a conclusion) by reasoning"; rare/proscribed sense "(math) to differentiate" (non-standard).
- **Consensus synonym:** "obtain by reasoning from given premises".
- **Our quiz answer:** "obtain by reasoning from given premises"
- **Verdict:** ✅ correct.

### Term 20: range of a linear map = image
- **Wikipedia:** https://en.wikipedia.org/wiki/Image_(mathematics) (accessed 2026-06-07) — "image" and "range" synonymous in linear-algebra usage. Wider math: "range" is ambiguous (can mean codomain).
- **Axler:** Uses "range" for image of a linear map (range T = {Tv : v ∈ V}).
- **Consensus:** In linear algebra (Axler-style) "range" = image.
- **Our current quiz:** "range of T" → synonym "image"
- **Verdict:** ✅ correct for linear-algebra context.
